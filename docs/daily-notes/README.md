# Daily notes

Two separate logs, one per side of the split established in
[`.github/copilot-instructions.md`](../../.github/copilot-instructions.md):

- [`backend/`](backend/) — Claude's log, `backend/` and repo-wide work
  (CI, branching, process).
- [`frontend/`](frontend/) — Copilot's log, `frontend/` work only.

Each folder has its own `TEMPLATE.md`; one file per day, named `YYYY-MM-DD.md`,
same `Done today` / `Plan for tomorrow` / `Blockers` shape either side.

## Why the split, and why this folder still has old files directly in it

The habit started as a single combined note per day (see
[`2026-08-13.md`](2026-08-13.md) — everything from that day, backend and
frontend both, before the two sides had separate territory worth logging
separately). That file stays as-is; it's the real historical record, not
worth rewriting. From the point this split was introduced onward, new
entries go in `backend/` or `frontend/` instead, written by whoever owns
that side.
