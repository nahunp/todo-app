  request silently blocked. Made allowed origins configurable instead
  of a hardcoded dev-only string.

  during 1.0 verification: a double-submitted delete threw an unhandled
  `DbUpdateConcurrencyException` (500) instead of a sensible response.
  Now maps to 404 in `GlobalExceptionHandler`. Also added
  `EnableRetryOnFailure()` for Azure SQL's free-tier serverless
  cold-start (confirmed via the App Service log stream, not guessed —
  Error 40613 the first time, a straight command timeout the second).
- **[PR #52](https://github.com/nahunp/todo-app/pull/52)** — documented
  the deployment in README.md and CLAUDE.md.

  review rounds that preceded today's third and merge.

  list → logout clears everything → route guard blocks unauthenticated
  access → the concurrent-delete fix confirmed by deliberately
